# Сборка RAG-цепочки в Langflow (пошагово)

Langflow-флоу — визуальный объект, и его JSON жёстко завязан на конкретную
версию Langflow (id компонентов, схема полей). Экспортированный "на глаз"
JSON часто ломается при импорте в другую версию. Поэтому вместо хрупкого
файла — пошаговая инструкция по сборке в UI, плюс уже готовый
индекс в Qdrant (см. `ingestion/build_index.py`), на который флоу
опирается.

Откройте http://localhost:7860 после `docker compose up -d`.

## Базовая цепочка (MVP)

```
Chat Input → Qdrant (Retrieval) → Prompt (с контекстом) → OpenAI/LLM → Chat Output
```

1. **Chat Input** — стандартный компонент, ничего настраивать не нужно.

2. **Qdrant** (категория Vector Stores) — компонент поиска по векторной БД:
   - Host: `qdrant` (имя сервиса в docker-compose, не `localhost` — Langflow
     обращается к Qdrant внутри той же docker-сети)
   - Port: `6333`
   - Collection Name: `rag_knowledge_base` (создаётся заранее скриптом
     `ingestion/build_index.py`, Langflow сюда не пишет, только читает)
   - Embedding: подключите тот же эмбеддер, что использовался при
     индексации (см. ниже "Согласованность эмбеддингов" — это частая
     ошибка новичков в RAG)
   - Number of Results: `100` — это и есть top-100 первого этапа

3. **Prompt** — шаблон с двумя переменными:
   ```
   Ответь на вопрос пользователя, используя только приведённый контекст.
   Если в контексте нет ответа — так и скажи, не выдумывай.

   Контекст:
   {context}

   Вопрос: {question}
   ```

4. **OpenAI** (или любой LLM-компонент) — модель из `.env` (`LLM_MODEL`),
   температура 0–0.2 (для фактологических ответов по закону креативность
   не нужна).

5. **Chat Output** — стандартный компонент.

## Добавление реранкинга (второй этап)

Между Qdrant и Prompt нужен компонент, сужающий top-100 до top-3/5:

- Если в вашей версии Langflow есть готовый **Reranker/Cohere Rerank**
  компонент — используйте его, указав self-hosted эндпоинт или
  подключив `retrieval/rerankers.py` через **Custom Component** (Langflow
  поддерживает произвольный Python-код в компоненте типа `Custom Component`
  — вставьте туда `BGERerankerCrossEncoder` из `retrieval/rerankers.py`).
- Если готового компонента нет — тот же **Custom Component** с телом:
  ```python
  from retrieval.rerankers import get_reranker
  reranker = get_reranker("bge")  # или "hash" для теста без сети
  return reranker.rerank(query, documents, top_k=5)
  ```

## Фильтрация по метаданным

В компоненте Qdrant есть поле **Filter** (JSON) — для фильтрации ДО
поиска по `article`/`chapter` из frontmatter документов:
```json
{"must": [{"key": "article", "match": {"value": "Статья 27"}}]}
```
Полезно, если пользователь в вопросе явно называет статью или тему —
можно сначала классифицировать вопрос (отдельный лёгкий LLM-вызов или
простое regex-правило), а потом сузить поиск фильтром.

## Согласованность эмбеддингов (частая ошибка)

Модель, которой индексировали корпус (`ingestion/build_index.py --backend
bge-m3`), и модель, которой Langflow векторизует входящий вопрос, должны
быть **той же самой моделью**. Разные модели эмбеддингов дают вектора в
разных пространствах — косинусное расстояние между ними бессмысленно.
Проверяйте `EMBEDDING_BACKEND` в `.env` и настройку эмбеддера в компоненте
Qdrant — они должны совпадать.

## Подключение Langfuse

В компоненте LLM (или в глобальных настройках Langflow, если версия
поддерживает интеграции) укажите:
- `LANGFUSE_PUBLIC_KEY` / `LANGFUSE_SECRET_KEY` — из
  http://localhost:3000 → Settings → API Keys (создать проект при первом
  входе)
- `LANGFUSE_HOST=http://langfuse:3000`

После этого каждый вызов флоу появится в Langfuse как трейс: видно
цепочку Retrieval → Prompt → LLM, токены, стоимость, латентность каждого
шага — и там же можно версионировать сам текст промпта.

## Экспорт флоу для README/GitHub

Когда цепочка собрана и работает — экспортируйте её (Langflow: меню флоу
→ Export) и сохраните в `langflow_flows/rag_pipeline.json` для репозитория.
Это тот самый файл, который стоит приложить к резюме/портфолио как
доказательство, что цепочка реально существует и импортируется.
