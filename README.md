## Теория

Полный конспект — [ML_THEORY_NOTES.md](ML_THEORY_NOTES.md). Можно спрашивать по любой из тем:

- Как классификаторы (LogReg, бустинг, Random Forest) устроены внутри
- Классификация vs регрессия vs кластеризация — когда что выбирать
- ROC-AUC vs PR-AUC
- Дисбаланс классов: SMOTE, undersampling, class weights
- Порог классификации через денежную метрику
- Cost-sensitive обучение
- Виды бустинга (AdaBoost, XGBoost, LightGBM, CatBoost) и других табличных алгоритмов
- Калибровка вероятностей
- Стабильность модели во времени (PSI)
- Прокси-таргеты
- Статистические тесты (Спирмен, ANOVA, хи-квадрат)
- Кросс-валидация vs бутстрап
